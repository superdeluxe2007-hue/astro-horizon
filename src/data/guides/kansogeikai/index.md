## 歓送迎会のご案内

Enlee（エンリー）は、福山市 中央公園の中にあるガーデンレストランです。中央図書館・まなびの館ローズコムのとなりにあります。送別会・歓迎会・歓送迎会を、貸切でお使いいただけます。

| | |
| --- | --- |
| ご人数 | 着席は65名様まで／半立食のブッフェは最大70名様まで |
| ご予算 | おひとり様 ¥6,000（税込・飲み放題付き）から |
| お時間 | 120分制・90分ラストオーダー |
| 場所 | 福山市霞町1-10-2（中央公園内） |

コースは「広島熟成どりのグリルコース」¥6,500 と「牛ミスジステーキコース」¥7,000 の2つです。屋外バーベキューは、中学生・高校生 ¥4,500、小学生 ¥3,500、5歳以下は無料です。

## 幹事様の段取り

1. お日にちの候補と、おおよそのご人数をお知らせください（公式LINE・お電話）
2. 会のかたちに合わせて、プランをご提案します
3. マイクやモニター、花束、記念品などのご希望をうかがいます
4. 最終のご人数を、ご利用日の3日前までにお知らせください
5. 当日、幹事様は開始の1時間前からお入りいただけます

3月と4月は、お日にちのご希望が重なりやすい時期です。お日にちが決まりましたら、お早めにご相談ください。
