## 忘年会・新年会のご案内

Enlee（エンリー）は、福山市 中央公園の中にあるガーデンレストランです。中央図書館・まなびの館ローズコムのとなりにあります。会社やグループの忘年会・新年会を、貸切でお使いいただけます。

| | |
| --- | --- |
| ご人数 | 着席は65名様まで／半立食のブッフェは最大70名様まで |
| ご予算 | おひとり様 ¥6,000（税込・飲み放題付き）から |
| お時間 | 120分制・90分ラストオーダー |
| 場所 | 福山市霞町1-10-2（中央公園内） |

## お料理は、コースとブッフェから

どちらも飲み放題付きです。

### ブッフェ ¥6,000（税込）

席を移りながら、たくさんの方とお話しいただけます。

- 前菜フィンガーフード4種
- 農園直送ハーブサラダ
- 鮮魚のカルパッチョ
- ミニハンバーガー
- フライドポテト
- チキンのグリル＆北海道産玉葱のグリル
- ピザマルゲリータ
- ミニデザート

### コース ¥6,500／¥7,000（税込）

席についてゆっくりお食事をお楽しみいただけます。

- 前菜盛り合わせ5種
- マグロのカルパッチョ
- 農園直送ハーブサラダ
- ピザマルゲリータ
- フライドポテト
- チキンのグリル＆野菜のグリル・北海道産玉葱のグリル
- ガーリックトースト
- 季節のソルベ

¥7,000 のコースは、メインが牛ミスジステーキになります。くわしくは [コース](/portfolio/course/)・[ブッフェ](/portfolio/buffet/) のページをご覧ください。

## ご予算の目安

飲み放題付きの料金に、ご人数をかけた金額です（税込）。

| ご人数 | ブッフェ ¥6,000 | コース ¥6,500 |
| --- | ---: | ---: |
| 30名様 | ¥180,000 | ¥195,000 |
| 40名様 | ¥240,000 | ¥260,000 |
| 60名様 | ¥360,000 | ¥390,000 |

お見積書をお出しします。会社のお支払いは、請求書でのお振り込みも承ります（請求書はメールでお送りします）。

## お日にちの選び方

金曜日の夜は、ご希望が重なりやすい曜日です。土曜日や平日の夜も、あわせてご検討ください。

貸切の日は、[営業カレンダー](/calendar/) でお知らせしています。候補のお日にちをいくつかお知らせいただければ、空いている日をお調べしてご提案します。

## 会の進行に

- **ごあいさつ・表彰・ビンゴ**：65インチのモニターとマイクのセット（¥5,000・税込）
- **一年のふり返りのスライド**：HDMIケーブルと無料 Wi-Fi をご用意しています
- **幹事様の準備**：開始の1時間前からお入りいただけます
- **もう少し続けたいとき**：延長はおひとり様30分 ¥500（税込）

会議や研修のあとの懇親会にもお使いいただけます。会場とお弁当をお探しの方は、[セミナー・研修の会場とお弁当](/guide/seminar-bento/) もご覧ください。
