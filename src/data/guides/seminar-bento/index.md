## 平日の日中に、会場とお昼をまとめてご用意します

Enlee（エンリー）は、福山市 中央公園の中にあるガーデンレストランです。平日の日中は、会社のセミナー・研修・説明会などにお使いいただけます。

会場は、会の内容に合わせて2つからお選びいただけます。

| | Enlee（中央公園内） | KOKON（姉妹店・明治町） |
| --- | --- | --- |
| 用途 | お食事を囲む会、懇親をかねた研修 | 講義・説明が中心のセミナー、勉強会 |
| 広さ | 店内40席・テラス25席 | 着席50名様・立食80名様 |
| 機材 | 65インチモニター＋マイクセット（¥5,000・税込） | プロジェクター・スクリーン・マイク・音響を常設（料金に含みます） |
| 料金 | お食事の内容とご人数に合わせてお見積りします | 半日（4時間）¥15,000／一日（8時間）¥25,000（税込） |
| ほか | 無料 Wi-Fi・HDMIケーブル | 無料 Wi-Fi・HDMIケーブル |

KOKONは、福山市明治町にあるEnleeの姉妹店です。くわしくは [KOKONのサイト](https://kokon-fukuyama.com/) をご覧ください。

## お見積りの例｜30名様のセミナー（半日）

午前に準備をして、2時間のセミナーのあと、そのままお席でお昼を召し上がっていただく場合の例です。

| 内訳 | 金額（税込） |
| --- | ---: |
| 会場（KOKON・半日4時間） | ¥15,000 |
| 自家製ローストビーフ弁当（お茶付き）¥1,980 × 30個 | ¥59,400 |
| **合計** | **¥74,400** |

おひとり様あたり ¥2,480（税込）です。お見積書をお出しします。お支払いは、請求書でのお振り込みも承ります。

お弁当だけのご注文も承ります。会議や撮影の現場、社内の集まりにもご利用いただけます。ご注文は、ご利用日の2営業日前までにお願いいたします。お受け取りはEnleeの店頭です。数の多いご注文は、お早めにご相談ください。

写真とくわしい内容は [お弁当・オードブルのページ](/takeout/) をご覧ください。

## お申し込みの流れ

1. ご希望の日時・ご人数・会の内容をお知らせください（公式LINE・お電話）
2. 会場とお弁当の内容をご提案し、お見積書をお送りします
3. 会場の下見もしていただけます
4. お弁当の数は、ご利用日の2営業日前までにお知らせください

懇親会やお食事つきの会をお考えでしたら、[貸切プラン](/portfolio/)（コース・ブッフェ・屋外バーベキュー）もご覧ください。
